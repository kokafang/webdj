# Jiafeng 的网页 DJ

用互联网视频拼贴成音乐的四路播放台。沿用当前版本的玻璃界面、流动氛围光、Crate 唱片箱、调性与关系调显示、侧边钢琴，以及两种斜体 About 滚动方式。

**这是在线版。** 视频通过 YouTube / Bilibili 官方播放器加载。仓库不包含下载的视频、离线封面缓存、下载工具、Obsidian 笔记或个人电脑路径。

## 打开

安装 Node.js 22 或更新版本，然后：

```sh
git clone https://github.com/kokafang/webdj.git
cd webdj
npm start
```

打开 **http://127.0.0.1:51960/**。无需安装 npm 依赖。

也可把 `public/` 部署到静态网站服务。`npm run build` 生成 `dist/`，兼容 GitHub Pages 的 `/webdj/` 子目录。自行部署到其他域名时，需要同时在扩展的 `manifest.json` 与 `protocol.js` 中明确添加该 WebDJ 域名。

## 使用

- 标题栏点击 **A / B** 或 **C / D**；切组保留四个播放器，声音可以继续叠加。
- 点 **Load**，选分类和唱片，再点 Load to A/B/C/D。也可以在每个 Deck 下直接贴视频链接。
- 右上角 **＋** 支持粘贴整段聊天文字，识别多个完整视频链接并去重。B站短链接需先展开为完整 BV/av 地址。
- 调性可编辑；Major / Minor 和关系调同时显示，变调后同步变化。个人修改和导入保存在当前浏览器，可在设置里导出 JSON 备份；不会改其他人的曲库。
- **About** 自动横向滚动；设置可选顶部白条或半透明全屏叠字。文字不拦截鼠标和触控；再点 About 收起。

初始库含 184 条在线来源记录。在线版播放原视频，因此不会沿用离线剪辑的时长；视频加载后读取实际长度。

## Chrome 扩展

电脑 Chrome 中，独立变调、精确变速、三段 EQ、独立输出音量和混响需要本仓库附带的扩展：

1. 打开 `chrome://extensions/`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本仓库的 **extension** 文件夹。
3. 刷新网页，装入视频，再点原播放器播放。扩展自动准备音频连接。

不需要再次点击扩展图标。升级后先在扩展管理页重新加载扩展，再刷新网页。

| 控制 | 范围 |
|---|---|
| 变调 | −12～+12 半音；大 − / ＋ 每次 1 半音，小 − / ＋ 每次 1 cent |
| 速度 | 10%～400%，1% 一步；100% 位于推子中点 |
| 输出音量 | 0%～100% |
| 高 / 中 / 低 EQ | −26～+6 dB，0.5 dB 一步 |
| Shimmer Reverb | 四路独立 Send，共用参数控制 |

EQ 与变调算法和当前离线版相同。扩展仅访问配置中的 WebDJ 站点与经过身份核对的官方播放器 frame，不捕获麦克风、不下载视频、不上传音频。新的音频图会在准备完成、浏览器允许音频运行后才接入媒体；不承诺所有平台都能零延迟接管。

## 在线播放器的边界

- 普通手机浏览器不能安装此桌面 Chrome 扩展。手机仍保留相同界面、选曲、原生播放、钢琴和 About；不可用的变调 / EQ 控件会禁用。
- 无扩展时，YouTube 的外部音量和速度使用官方 API；速度受平台支持的档位限制。Bilibili 使用播放器本身的播放与音量控件。
- 不覆盖官方播放器的原生控制栏。广告、登录、地区、嵌入许可和网络可能影响视频播放；源码公开不保证每条来源始终可播。
- 跨域 iframe 无法直接进入同一个网页音频总线。扩展在四个播放器内部各运行一个混响，共用设置；合计听感和限幅不等同于离线版的单一总线。
- 在线原生跳转不提供离线版的双解码器交叠。扩展保留结尾淡出；原生播放器的暂停按钮不承诺提前淡出。
- 无扩展时氛围光取在线封面；扩展连接后尝试取实时画面。平台拒绝图像读取时继续显示封面。
- 个人导入与修改不是共享后台。公开版不提供 Obsidian 写回入口，也不上传修改。

播放器接口参考：[YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)、[Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。
